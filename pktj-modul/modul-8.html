8.1 NIC (Network Interface Card)
🔌
NIC / LAN Card
"Pintu masuk" perangkat ke jaringan

NIC adalah perangkat keras yang memungkinkan komputer terhubung ke jaringan. Setiap NIC memiliki alamat fisik unik yang disebut MAC Address (48 bit, ditulis dalam 6 pasang heksadesimal).

Fungsi Utama

  • Menghubungkan komputer ke media transmisi (kabel atau nirkabel).
  • Mengubah data dari komputer menjadi sinyal yang bisa dikirim.
  • Menyediakan MAC Address sebagai identitas unik.
  • Menangani komunikasi data (kirim/terima, error checking).

Jenis NIC

JenisMediaKecepatan Umum
EthernetKabel UTP100 Mbps – 10 Gbps
WirelessWi-Fi100 Mbps – 9.6 Gbps
FiberFiber optic1 Gbps – 100 Gbps

Bentuk Fisik

  • Onboard — sudah menempel di motherboard (paling umum).
  • PCIe card — dipasang di slot PCIe (untuk server / PC high-end).
  • USB adapter — untuk laptop atau perangkat tanpa slot PCIe.
  • Module — untuk laptop tertentu (misal laptop bisnis).
Bottleneck Tersembunyi

NIC 100 Mbps di server akan membatasi semua client meski switch-nya 1 Gbps. Cek NIC sebelum menyalahkan switch.

Cara Cek MAC Address

Windows: ipconfig /all
Linux/Mac: ip link atau ifconfig

8.2 Hub
📡
Hub
Perangkat lama — hampir punah, tapi penting untuk dipahami

Hub adalah perangkat jaringan paling sederhana. Fungsinya hanya "mengulang" sinyal yang diterima ke semua port lain. Sudah jarang dipakai karena keterbatasannya.

Cara Kerja Hub

  • Data yang masuk ke satu port akan dikirim ke semua port lain.
  • Hanya bekerja di satu collision domain — semua port berebut jalur.
  • Tidak bisa membaca MAC Address — tidak tahu tujuan data.
  • Bersifat half-duplex — kirim atau terima, tidak bisa bersamaan.

Keterbatasan Hub

AspekMasalah
BandwidthSemua port berbagi satu jalur
KeamananSemua perangkat bisa "mendengar" data
CollisionSering terjadi tabrakan data
KecepatanTurun drastis saat banyak port aktif
Sudah Tidak Dipakai

Hub sudah digantikan switch. Kalau Anda menemukan hub di jaringan modern, sebaiknya diganti dengan switch.

Kenapa Masih Dipelajari?

Untuk memahami mengapa switch lebih baik. Tanpa tahu kelemahan hub, sulit memahami nilai switch.

8.3 Switch
🔀
Switch
Jantung jaringan lokal — perangkat paling penting di LAN

Switch adalah perangkat yang menghubungkan banyak perangkat dalam satu jaringan lokal. Berbeda dengan hub, switch membaca MAC Address dan hanya mengirim data ke port tujuan.

Cara Kerja Switch

  1. Belajar MAC Address — switch mencatat MAC Address setiap perangkat yang terhubung.
  2. Membangun MAC table — tabel yang memetakan MAC Address ke port.
  3. Forward selektif — data dikirim hanya ke port tujuan.
  4. Full-duplex — semua port bisa kirim & terima bersamaan.

Keunggulan Switch vs Hub

AspekHubSwitch
Domain collision1 untuk semua1 per port
KeamananData terkirim ke semuaHanya ke tujuan
BandwidthDibagi semua portFull per port
DuplexHalf-duplexFull-duplex
KinerjaTurun saat ramaiStabil

Fitur Umum Switch

MAC Address Table
  • Menyimpan daftar MAC & port
  • 4K–16K entries umum
  • Menentukan kemana data dikirim
Auto-negotiation
  • Deteksi kecepatan otomatis
  • 10/100/1000 Mbps
  • Tanpa konfigurasi manual
VLAN (jika managed)
  • Segmentasi logis
  • Isolasi traffic antar grup
  • Keamanan & manajemen
PoE (jika didukung)
  • Kirim daya via kabel data
  • Untuk AP, CCTV, VoIP
  • Budget total dibatasi
8.4 Managed & Unmanaged Switch

Switch dibedakan menjadi dua berdasarkan kemampuan konfigurasi: managed (bisa diatur) dan unmanaged (plug-and-play).

Unmanaged Switch
  • Plug-and-play, tanpa konfigurasi
  • Harga murah
  • Tidak bisa VLAN, QoS, monitoring
  • Cocok: rumah, kantor kecil
  • Contoh: switch 8-port Rp150rb
Managed Switch
  • Bisa dikonfigurasi (web/CLI)
  • Support VLAN, QoS, SNMP
  • Bisa monitoring & troubleshooting
  • Cocok: kantor, sekolah, enterprise
  • Contoh: switch 48-port Rp4–8 juta

Perbandingan Detail

FiturUnmanagedManaged
KonfigurasiTidak adaWeb / CLI / Cloud
VLAN✗✓
QoS✗✓
Monitoring (SNMP)✗✓
Port mirroring✗✓
Link aggregation✗✓
HargaMurah2–10× lebih mahal
KemudahanSangat mudahButuh keahlian
Smart / Web-Smart Switch

Ada kategori di tengah — smart switch atau web-smart switch. Bisa dikonfigurasi via web, tapi fiturnya lebih terbatas dari managed penuh. Cocok untuk SMB dengan anggaran terbatas.

Kapan Pilih Managed?

Pilih managed jika:
• Ada kebutuhan VLAN (pisah traffic guru/siswa/tamu)
• Ada QoS (prioritas VoIP/video conference)
• Butuh monitoring jaringan
• Skala jaringan akan berkembang

8.5 Layer 2 & Layer 3 Switch

Switch bekerja di lapisan OSI Layer tertentu. Layer 2 switch bekerja berdasarkan MAC Address, Layer 3 switch bisa routing berdasarkan IP Address.

Layer 2 Switch
  • Bekerja di Data Link Layer (OSI L2)
  • Forward berdasarkan MAC Address
  • Tidak bisa routing antar VLAN
  • Butuh router untuk komunikasi antar jaringan
  • Harga lebih murah
Layer 3 Switch
  • Bekerja di Network Layer (OSI L3)
  • Bisa routing berdasarkan IP
  • Bisa routing antar VLAN (inter-VLAN routing)
  • Lebih cepat dari router untuk routing internal
  • Harga lebih mahal

Perbandingan

AspekL2 SwitchL3 Switch
Basis forwardingMAC AddressMAC + IP Address
Routing antar VLANTidak bisaBisa
Routing protocolTidak adaStatic, RIP, OSPF
Kecepatan routing—Lebih cepat dari router
Cocok untukAccess layerCore / distribution

Kapan Pakai L3 Switch?

  • Jaringan dengan banyak VLAN (sekolah, kantor besar).
  • Butuh routing internal cepat tanpa router terpisah.
  • Backbone / core layer jaringan hierarkis.
  • Mengurangi beban router untuk traffic antar VLAN.
Istilah "Layer 2+"

Beberapa vendor menyebut switch-nya "L2+" atau "L2 with static routing". Ini L2 switch dengan kemampuan routing statis terbatas. Bukan L3 penuh, tapi lebih dari L2 biasa.

8.6 Router
🌐
Router
Pintu gerbang antara jaringan lokal dan internet

Router menghubungkan dua atau lebih jaringan yang berbeda. Ia membaca IP Address dan menentukan rute terbaik untuk paket data.

Fungsi Utama Router

  • Routing — menentukan jalur terbaik untuk paket data.
  • NAT — menerjemahkan IP privat ke IP publik (agar banyak perangkat bisa share 1 IP publik).
  • DHCP Server — memberi IP otomatis ke perangkat di jaringan.
  • Firewall dasar — memfilter traffic masuk/keluar.
  • VPN — koneksi aman antar jaringan.
  • QoS — memprioritaskan traffic tertentu.

Jenis Router Berdasarkan Konteks

JenisCocok untuk
Router rumahanRumah, kantor kecil — all-in-one (router + Wi-Fi + switch)
Router SMBKantor kecil–menengah — multi-WAN, VPN
Router enterpriseKantor besar, sekolah — modular, routing protocol
Router coreData center, ISP — throughput sangat tinggi
Jebakan Umum

Router dengan port 1 Gbps belum tentu bisa routing 1 Gbps. Lihat routing throughput di datasheet — sering hanya 300–500 Mbps di router kelas menengah.

Router vs Switch

Analogi sederhana:
• Switch = kantor pos dalam satu kota (antar alamat MAC).
• Router = kantor pos antar kota (antar alamat IP).

8.7 Wireless Access Point
📶
Access Point
Jembatan antara jaringan kabel dan perangkat nirkabel

Access Point (AP) memungkinkan perangkat nirkabel (laptop, HP, tablet) terhubung ke jaringan kabel. AP "mengubah" sinyal kabel menjadi sinyal Wi-Fi.

Fungsi AP

  • Menyediakan Wi-Fi — memancarkan sinyal untuk client.
  • Bridge kabel ↔ wireless — menghubungkan dua media berbeda.
  • Autentikasi — mengelola siapa yang boleh terhubung (WPA2/WPA3).
  • Manajemen client — membagi bandwidth, roaming.

Bentuk AP

Ceiling-mount
  • Dipasang di plafon
  • Coverage merata ke bawah
  • Umum di kantor & sekolah
Wall-mount
  • Dipasang di dinding
  • Untuk ruangan tertentu
  • Kadang tampil seperti outlet
Outdoor AP
  • Tahan cuaca (IP65+)
  • Untuk area luar
  • Jangkauan luas
Router Wi-Fi
  • Gabungan router + AP
  • Untuk rumah / kantor kecil
  • All-in-one
AP vs Router Wi-Fi

AP hanya menyediakan Wi-Fi. Router Wi-Fi = router + AP + switch dalam satu perangkat. Di kantor, biasanya dipisah: router khusus + AP terpisah.

Controller vs Standalone

• Standalone — tiap AP dikonfigurasi terpisah. Cocok untuk 1–3 AP.
• Controller-based — banyak AP dikelola dari satu titik. Cocok untuk 5+ AP.
• Cloud-managed — dikelola dari cloud. Cocok untuk multi-lokasi.

8.8 Modem / ONT
📞
Modem / ONT
Penerjemah sinyal dari ISP ke jaringan lokal

Modem (Modulator-Demodulator) mengubah sinyal dari ISP menjadi sinyal digital yang bisa dipakai jaringan lokal. ONT (Optical Network Terminal) adalah modem khusus untuk fiber optic.

Jenis Modem Berdasarkan Media ISP

JenisMedia ISPUmum di
ADSL ModemKabel teleponLangganan lama (Speedy)
Cable ModemKabel TVTV kabel + internet
ONT (Fiber)Fiber opticIndiHome, Biznet, MyRepublic
4G/5G ModemSelulerBackup / area tanpa kabel

Fungsi Modem / ONT

  • Mengubah sinyal ISP (analog/optik) menjadi sinyal digital (Ethernet).
  • Sering sudah termasuk router + Wi-Fi (all-in-one).
  • Bisa bridge mode — modem hanya meneruskan, router terpisah menangani routing.
  • Menyediakan port untuk TV kabel / telepon (jika satu paket).
Bridge Mode

Kalau Anda pakai router sendiri yang lebih bagus, aktifkan bridge mode di modem/ONT. Modem hanya jadi "pipa", semua routing dilakukan router Anda. Menghindari double NAT.

Milik Siapa?

Modem/ONT biasanya milik ISP dan dipinjamkan selama berlangganan. Jangan asal ganti tanpa izin ISP — bisa putus koneksi.

8.9 Firewall
🛡️
Firewall
Satpam jaringan — menyaring traffic yang boleh masuk

Firewall memeriksa setiap paket data yang masuk atau keluar dari jaringan dan memutuskan: izinkan atau blokir, berdasarkan aturan yang ditentukan.

Jenis Firewall

JenisCara KerjaLevel
Packet FilteringFilter berdasarkan IP & portDasar
Stateful InspectionMelacak status koneksiMenengah
UTM / NGFWAntivirus, IPS, content filterLanjut
WAFKhusus aplikasi webKhusus

Bentuk Firewall

  • Software firewall — terinstall di PC/server (Windows Firewall, iptables).
  • Router firewall — fitur di router (sudah cukup untuk kecil).
  • Appliance firewall — perangkat khusus antara router & LAN.
  • Cloud firewall — disediakan oleh layanan cloud.

Fungsi Umum Firewall

  • Blokir akses tidak sah dari luar.
  • Filter konten (parental control, block situs).
  • Deteksi & blokir serangan (IPS/IDS).
  • Log aktivitas jaringan untuk audit.
  • Membuat VPN antar lokasi.
Untuk Skala Kecil

Untuk rumah & kantor kecil, firewall bawaan router sudah cukup. Beli appliance firewall terpisah hanya jika ada kebutuhan spesifik (audit, IPS, content filtering serius).

Lisensi

Firewall UTM/NGFW biasanya butuh lisensi tahunan untuk update signature. Jangan hanya lihat harga beli — hitung juga biaya lisensinya.

8.10 Server
🖥️
Server
Komputer yang melayani — bukan dilayani

Server adalah komputer (atau perangkat) yang menyediakan layanan bagi komputer lain (client). Di jaringan, server biasanya diakses oleh banyak client bersamaan.

Jenis Server Berdasarkan Fungsi

File Server
  • Menyimpan & berbagi file
  • Bisa diakses banyak client
  • Butuh storage besar
Web Server
  • Menyajikan aplikasi web
  • Akses via browser
  • Contoh: LMS sekolah
Database Server
  • Menyimpan & mengelola data
  • Query dari aplikasi lain
  • Butuh RAM & disk cepat
Print Server
  • Mengelola printer jaringan
  • Bisa dari router/NAS
  • Antrian & driver management

Bentuk Server

BentukCiriCocok untuk
TowerBerdiri, seperti PC besarKantor kecil, sekolah
Rack-mount (1U/2U/4U)Datar, dipasang di rackData center, kantor menengah
BladeModular dalam chassisEnterprise, efisiensi ruang
NASKotak penyimpanan jaringanRumah, kantor kecil

Server vs PC Biasa

AspekPC BiasaServer
Uptime8 jam/hari24/7
Prosesor1 CPU umumMulti-CPU / Xeon
RAM8–32 GB64 GB – 1 TB+
Storage1 diskRAID (disk berlapis)
RedundansiTidak adaPSU ganda, cooling
HargaRp5–15 jutaRp30 juta – ratusan juta
Bottleneck NIC

Server dengan NIC 1 Gbps hanya bisa melayani ~125 MB/detik. Kalau 36 client transfer file bersamaan, akan terasa lambat. NIC 2.5G atau 10G sering diperlukan untuk server file.

8.11 PoE Switch & PoE Injector

PoE (Power over Ethernet) mengirim daya listrik bersamaan dengan data melalui satu kabel UTP. Berguna untuk perangkat yang sulit dijangkau colokan listrik.

Perangkat yang Cocok Pakai PoE

  • Access Point — dipasang di plafon, tanpa colokan dekat.
  • CCTV / IP Camera — dipasang di lokasi yang tidak ada listrik.
  • Telepon VoIP — meja kerja, satu kabel untuk data & daya.
  • Perangkat IoT — sensor, akses kontrol.

Standar PoE

StandarNamaDaya per Port
802.3afPoE15.4 W
802.3atPoE+30 W
802.3bt Type 3PoE++60 W
802.3bt Type 4PoE++90 W

Dua Cara Memberi PoE

PoE Switch
  • Switch sudah punya PoE built-in
  • Semua port PoE (atau sebagian)
  • Budget total (misal 190W)
  • Cocok: banyak perangkat PoE
PoE Injector
  • Alat kecil di antara switch & perangkat
  • Satu injector untuk satu perangkat
  • Butuh colokan listrik per injector
  • Cocok: perangkat PoE sedikit (1–3)

Hitung Budget PoE

Total PoE = Σ (jumlah perangkat × daya perangkat)

Contoh: 8 AP × 15W = 120W
Budget switch harus ≥ 120W
PoE Budget ≠ Per Port

Switch 24-port PoE+ dengan budget 190W tidak bisa memberi 30W ke semua port (24 × 30 = 720W). Yang dibatasi adalah total, bukan per port.

Tips

Sisakan minimal 20% cadangan PoE budget untuk perangkat tambahan di masa depan.

8.12 SFP dan Transceiver

SFP (Small Form-factor Pluggable) adalah modul transceiver yang bisa dilepas-pasang di slot switch/router. Fungsinya mengubah sinyal listrik menjadi sinyal optik (fiber) — atau sebaliknya.

Jenis SFP

JenisKecepatanUmum untuk
SFP1 GbpsUplink jarak menengah
SFP+10 GbpsBackbone, server
SFP2825 GbpsData center
QSFP+40 GbpsBackbone besar
QSFP28100 GbpsData center core

Jenis Kabel di SFP

Fiber Optic
  • Jarak jauh (100 m – puluhan km)
  • Butuh SFP khusus (SM/MM)
  • Kecepatan tinggi
DAC Cable
  • Direct Attach Copper
  • Jarak pendek (1–7 m)
  • Lebih murah dari fiber
  • Untuk koneksi rack internal
AOC Cable
  • Active Optical Cable
  • Jarak menengah (10–100 m)
  • Sudah termasuk transceiver
Copper RJ45 SFP
  • SFP dengan port RJ45
  • Untuk kabel UTP
  • Jarak 100 m
Kenapa SFP Penting?

SFP memungkinkan switch/router dipasang koneksi fiber tanpa harus beli perangkat baru. Fleksibel untuk upgrade.

Kompatibilitas

Tidak semua SFP kompatibel dengan semua switch. Beberapa vendor mengunci SFP hanya untuk merek mereka. Cek datasheet sebelum beli.

8.13 Rack & Perangkat Pendukung

Perangkat jaringan profesional dipasang di rack — lemari khusus dengan ukuran standar. Rack bukan sekadar tempat, tapi bagian dari manajemen infrastruktur.

Ukuran Rack

1U = 1.75 inci = 44.45 mm (tinggi)

Lebar standar: 19 inci (482 mm)
Ukuran umum tinggi: 6U, 9U, 12U, 22U, 42U

Komponen Rack

Rack Frame
  • Struktur utama (logam)
  • Terbuka atau tertutup
  • Ada pintu & kunci
PDU
  • Power Distribution Unit
  • Stop kontak rack-mounted
  • Bisa monitored / switched
Patch Panel
  • Terminasi kabel UTP
  • 24 / 48 port
  • Rapi & mudah di-manage
Cable Manager
  • Mengatur jalur kabel
  • Horizontal & vertikal
  • Mencegah kabel kusut
Fan / Cooling
  • Sirkulasi udara dalam rack
  • Penting untuk server
  • Termostat otomatis
Shelves & Bracket
  • Rak untuk perangkat non-rack
  • Bracket untuk mounting
  • Baut & mur standar M6

Perhitungan Ukuran Rack

Total U = Σ tinggi perangkat + 2U (organizer) + cadangan 30%

Contoh:
Switch 1U + Patch Panel 2U + Router 1U + Server 1U
+ NVR 2U + UPS 2U + Cable mgr 2U = 11U
+ 30% cadangan = 15U → pilih rack 22U
Tips

Jangan beli rack "pas-pasan". Selalu pilih satu ukuran di atas kebutuhan, agar ada ruang untuk upgrade & sirkulasi udara.

Latihan

Poin Kunci Modul 8

  1. NIC = interface fisik ke jaringan, punya MAC Address.
  2. Hub = broadcast ke semua port (lama, tidak dipakai lagi).
  3. Switch = forward selektif berdasarkan MAC. Jantung LAN.
  4. Managed switch = bisa VLAN, QoS, monitoring. Unmanaged = plug-and-play.
  5. L3 switch = bisa routing antar VLAN, lebih cepat dari router.
  6. Router = hubungkan jaringan berbeda, NAT, DHCP, firewall.
  7. Access Point = Wi-Fi dari jaringan kabel.
  8. Modem/ONT = penerjemah sinyal ISP ke jaringan lokal.
  9. Firewall = saring traffic berdasarkan aturan keamanan.
  10. Server = melayani; PC = dilayani.
  11. PoE = daya + data via satu kabel. Budget total, bukan per port.
  12. SFP = modul fiber fleksibel untuk uplink cepat.
  13. Rack = pemasangan standar 19". Ukuran dalam U.
  14. Setiap perangkat punya peran, bukan hanya nama.
